# seaharness-document-script

Full Codex-class DOCX authoring pack: task playbooks, OOXML helpers, writing quality, Google Docs sanitizer, and one python-docx builder plus document_open(publish=true). HTML/Markdown/FolkDoc still use document_create.

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/seaharness-document-script#v2.0.4 --skill seaharness-document-script
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill seaharness-document-script
```

## 内容

技能正文在 `skills/seaharness-document-script/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/seaharness-document-script/payload/`，不要反向同步。版本以 git tag 为准。
